# LoL Draft Predictor

Pick five pro players and five champions for each side and see who the model expects to win, before the game and if
it is still going at minutes 20 to 40. Live at https://adamhibbert21.github.io/lol-draft-prediction-model/

The page is static: the win model runs in the browser from `data/site.json`. The data pipeline and model training
live in a separate repository.

Pro game data: gol.gg and Leaguepedia (CC BY-SA). Lane counter data: u.gg.
